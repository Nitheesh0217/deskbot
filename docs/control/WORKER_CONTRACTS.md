# Worker contracts for the target-fit and late-entry work (Part F)

These are existing seats only; no new workers are added. "Implementation" describes what runs today (CURRENT_STATE.md: several seats are labels over shared engine code, not independent agents). A seat is healthy only when its evidence is present and fresh. Missing evidence is shown as MISSING, never as OK.

| Seat | Responsibility here | Observable inputs | Outputs | Trigger | Freshness limit | Failure handling | Evidence | Implementation |
|---|---|---|---|---|---|---|---|---|
| **Ada** (structure) | Market structure the plan refers to: Donchian trigger, swing highs/lows, broken levels | Closed h4/h1 bars of the decision (`dbv5_decision_inputs`) | `structureRefs` (trigger level, nearest opposing level, distance in ATR/R) | Each closed 4H bar | 1 bar (4 h) | Inputs missing → "structure unknown"; never draw a stale level as current | Values reproducible from the stored bars | Chart code (engine snapshot `hi4h/lo4h`) |
| **Zed** (volatility/zones) | ATR of the strategy's own timeframe, ATR% tercile, advisory zones | Same bars; `zones.ts` | `atrTf`, `atrPct`, regime tercile, zones marked *Advisory* | Each run | 1 strategy bar | No ATR → plan panel shows "ATR unavailable"; zones hidden by default | ATR recomputed from the stored bars matches the record (done for D-V5-1793318461202: 1,059.465) | `zones.ts` + engine snapshot (label over code) |
| **Sage** (eligibility) | First eligible signal, first trigger time, rejections | `evaluate()` signals and rejects | Per run: signal list, reject reasons, `snapshotBarClose`, first observable intrabar cross (research) | Each cron run | Run cadence (5 min) | Evaluation error → no entry; logged reject "evaluation failed" | `record.candidates` in the decision record | Engine `evaluate` |
| **Quinn** (geometry) | Stop, R, targets, quantities, units | Signal stop, fill, `CFG.TARGETS`, sizing | `plan` (entry, stop0, tp1-3, originalQty, riskAmt) | On entry | Immutable after entry | Plan fails a unit check → no entry | `plan` + `config` hash in the decision record; Part B recomputation | Engine `openPosition` |
| **Val** (independent check) | Recompute the plan from inputs, compare displayed vs stored | Decision record, stored inputs, dashboard plan rows | PASS / MISMATCH per field (price, R from stop0, %, qty, costs) | After each entry and each dashboard build | Per entry | Mismatch → flag on the position card; never edit the plan | `tests/plan_rows.test.ts`, Part B table | Validator seat + `web/plan.js` |
| **Theo** (management) | Partials, stop moves, giveback, time exits | Open position, 1m/5m path | Work-log records for each fill / stop move / close; MFE and giveback | Each run while a position is open | 5 min | Outbox keeps records until acked; backlog, oldest age and last flush shown | `dbv5_agent_log` work keys; `work.lastFlush` | `worklog.ts` (W2, release pending) |
| **Rex** (provenance) | Decision records and missing-record reporting | `dbv5_decisions`, `dbv5_decision_inputs` | Record hash, list of positions without a record | Each entry; daily sweep | 1 day | Missing record → "missing telemetry", never inferred | `record_sha256`; count of trades before 2026-10-29 17:26 with no record | `provenance.ts` (label over runner code) |
| **Pat** (post-trade) | Per-trade excursion review after close | Closed trade + its record | MFE/MAE in %/ATR/R, time to targets, giveback, entry-delay decomposition | On close | 1 day after close | Record missing → review marked incomplete | ENTRY_DELAY.md format | desk-postmortem |
| **Rhea** (offline research) | Frozen specs, M1, challengers | Frozen dataset + hashes, FREEZE.json | RUN_LOG.jsonl, M1_SUMMARY.md, CHALLENGERS.md | Manual, logged invocation only | N/A (frozen) | Hash mismatch → abort the run | `research/2026-10-30-entry-exit/` | Offline scripts |
| **Reese** (risk limits) | Enforce approved limits; never changed by this research | Equity, open risk, daily limits | Gate pass/fail with reason | Each entry attempt | Per run | Gate error → block the entry | `entryGates` result in the record | Engine `entryGates` (label over code) |

Rules shared by all seats: a challenger output is advisory/shadow only; no seat may modify an open position's plan; no seat displays a target-hit probability; stops are never tightened to make targets look closer.
