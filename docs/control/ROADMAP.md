# Dependency-ordered roadmap

| Milestone | Deliverable | Gate |
|---|---|---|
| M0 | Repository/branch audit, control pack, skill review, read-only evidence observer | Local checks pass; GitHub publication verified; current access gaps explicit |
| M1 | Exact deployed source/config/schema reconciliation | Authorized read access; artifact/config history captured; no version-string-only verification |
| M2 | One instrument decision record → paper events → reconciled outcome → existing UI detail | Immutable decision evidence, exact feed/contract, duplicate/restart/failure tests; no invented fields |
| M3 | Reproducible baseline and experiment registry | Hashed datasets, matching execution inputs/costs, all trials retained, untouched evaluation boundaries |
| M4 | One bounded filter challenger and post-trade reviews | Same baseline opportunities, risk and executor; no future information; uncertainty and failure results retained |
| M5 | Approved-universe radar and timestamped catalyst evidence | Eligibility registry and point-in-time scanner selection included in evaluation |
| M6 | Six-workspace dashboard incrementally extended from existing views | Real records, correct labels, loading/stale/error states and traceable metric definitions |
| M7 | Separate production-readiness review | Security, transactional/fenced state, recovery, alert delivery and permissions verified |

M1 is the critical path. Local documentation/research can continue without project access, but exact live-path claims cannot. M2 onward are not marked shipped by this branch. Funded execution and capital growth targets are not milestones automatically authorized by software completion.
